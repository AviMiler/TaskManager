# Task Manager - מערכת ניהול משימות

מערכת פשוטה ומהירה לניהול פרוייקטים ומשימות עם בסיס נתונים מקומי וגיבוי אוטומטי.

## תכונות

✨ **פשוט ומינימלי** - ממשק נקי וקל לשימוש
🚀 **מהיר** - בסיס נתונים SQLite מקומי
💾 **גיבוי אוטומטי** - שני עותקים (אחד לשימוש, אחד לגיבוי)
📱 **רেספונסיבי** - עובד על דסקטופ וטלפון
🔒 **מקומי** - כל הנתונים נשמרים על המחשב שלך

## הנתונים נשמרים במקום בטוח

```
/home/user/TaskManager/data/
├── tasks.db          (בסיס הנתונים הראשי - לשימוש יומיומי)
└── tasks.db.backup   (גיבוי - מתעדכן בכל שינוי)
```

כל פעם שאתה מוסיף/משנה/מוחק משימה או פרוייקט, גיבוי חדש נוצר אוטומטית.

## התקנה

1. **התקן Python 3.8+** (אם עדיין לא התקנת)

2. **התקן תלויות:**
```bash
pip install -r requirements.txt
```

3. **הפעל את האפליקציה:**
```bash
python app.py
```

4. **פתח בדפדפן:**
```
http://localhost:5000
```

## שימוש

### הוסף פרוייקט
- הקלד את שם הפרוייקט בחלון השמאלי
- לחץ "➕ הוסף"

### הוסף משימה
- בחר פרוייקט
- הקלד כותרת משימה (ותיאור אופציונלי)
- לחץ "➕ הוסף משימה"

### עדכן משימה
- לחץ על ✏️ כדי לערוך כותרת או תיאור
- סמן ☑️ כדי לסמן כהשלום/לא השלום

### מחק משימה או פרוייקט
- לחץ על 🗑️

## הגיבוי שלך

בסיס הנתונים שלך מוזה בשני קבצים:
- **tasks.db** - השימוש שלך היומיומי
- **tasks.db.backup** - גיבוי אוטומטי שנוצר בכל שינוי

אתה יכול גם להעתיק את הקבצים לאתר אחר לשמירה נוספת.

## פרטיות וביטחון

✅ כל הנתונים נשמרים מקומית - לא נשלחים לשום שרת
✅ אין מעקב, אין רשומות - זה שלך בלבד

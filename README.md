# Task Manager - מערכת ניהול משימות 📋

✅ **פשוט ומינימלי** - ממשק נקי וקל לשימוש

💾 **גיבוי אוטומטי** - גיבוי דו-שכבתי בכל פעם שאתה משנה משהו  
📱 **רেספונסיבי** - עובד על דסקטופ וטלפון  
🔒 **מקומי לחלוטין** - כל הנתונים נשמרים בדפדפן - לא נשלחים לשום שרת  

## 🚀 התחלה

### דרך פשוטה ביותר:
1. כנס לתיקיית `TaskManager`
2. לחץ פעמיים על `index.html` **או** גרור אותו לדפדפן שלך
3. זהו! האפליקציה פתוחה ומוכנה להשתמש

### או בדפדפן:
1. פתח את הדפדפן שלך (Chrome, Firefox, Edge, Safari)
2. הקש `Ctrl+O` (Windows) או `Cmd+O` (Mac)
3. בחר את הקובץ `index.html`
4. לחץ "פתח"

## 💾 איפה הנתונים שלי?

כל הנתונים שלך נשמרים **בדפדפן שלך** (localStorage):

### יש שני קבצים "וירטואליים":
1. **tm_projects** - רשימת הפרוייקטים שלך
2. **tm_tasks** - כל המשימות שלך
3. **tm_backup** - גיבוי אוטומטי שנוצר בכל שינוי

אתה יכול לראות אותם ב:
- **Chrome/Edge**: `F12` → Application → Local Storage
- **Firefox**: `F12` → Storage → Local Storage

## 📖 איך משתמשים?

### ➕ הוסף פרוייקט
1. הקלד שם בשדה "שם פרוייקט חדש..." בשמאל
2. לחץ על הכפתור ➕ או לחץ Enter

### ➕ הוסף משימה
1. בחר פרוייקט מהרשימה בשמאל
2. הקלד כותרת משימה בשדה "כותרת המשימה..."
3. (אופציונלי) הוסף תיאור למטה
4. לחץ "➕ הוסף משימה" או לחץ Enter

### 🔄 שנה מצב משימה

המשימות שלך מוצגות בלוח **Kanban** עם 3 עמודות:

| 🔴 לביצוע | 🟠 בביצוע | 🟢 בוצע |
|---|---|---|
| משימות חדשות | משימות בתהליך | משימות הושלמו |

- לחץ על כפתור המצב בתוך המשימה כדי להעביר אותה בין עמודות
- או אפשר גרירה ושחרור בקרוב!

### ✏️ ערוך משימה
- לחץ על הכפתור ✏️
- שנה את הכותרת או התיאור
- לחץ "שמור"

### 🗑️ מחק
- לחץ על 🗑️ ליד המשימה או הפרוייקט
- אישר את המחיקה

## ⚠️ זהירות!

### נטיפול למשתמשים מתקדמים:

**אם תמחק את ה-localStorage של הדפדפן**, כל הנתונים שלך יאבדו!
- **Chrome**: Settings → Privacy → Clear browsing data → Cookies and other site data
- **Firefox**: Preferences → Privacy → Cookies and Site Data → Clear Data
- **Edge**: Settings → Privacy → Clear browsing data

### איך לשמור גיבוי למחשב:
1. פתח את F12 (Developer Tools)
2. עבור ל-Application → Local Storage → (שם הדפדפן)
3. בחר את `tm_backup`
4. הוא יפתח בconsole - תוכל להעתיק אותו ולשמור לקובץ .json

## 🚀 טיפים שימושיים

- **Keyboard Shortcuts:**
  - `Enter` בשדה פרוייקט = הוסף פרוייקט
  - `Enter` בשדה כותרת משימה = הוסף משימה
  - `Esc` בחלון עריכה = בטל
  - לחץ על מצב כדי להעביר משימה בין עמודות

- **עזרה לנתונים תקועים:**
  - רענן את הדפדפן (`F5` או `Ctrl+R`)
  - לחץ "נקה הכל" 🗑️ בתחתית (זה מחק הכל - התנה!)

- **לוח Kanban:**
  - שלוש עמודות: לביצוע (🔴) / בביצוע (🟠) / בוצע (🟢)
  - עברות קלות בין עמודות - בחר מצב חדש
  - סדר המשימות נשמר לפי זמן יצירה

## 📝 מה אם נתקל בבעיה?

### הנתונים לא נשמרים:
1. וודא שהדפדפן מאופשר אחסון (localStorage)
2. בדוק שאתה לא בתצורת "Incognito/Private"
3. וודא שדיסק קשיח יש מקום פנוי

### הקובץ לא נפתח:
1. תנסה דפדפן אחר
2. וודא שאתה פותח את `index.html` (לא css או js)
3. אם זה עדיין לא עובד, תוכל להעתיק את הטקסט מה-html לקובץ חדש

## 🎯 רעיונות לתכונות נוספות (סגנון Jira)

### פשוטים וקלים להוסיף:

#### 📌 **תעדוף (Priority)**
```
🔴 Critical / High
🟡 Medium  
🟢 Low
```
- הוסף תיאום צבע לכל תעדוף
- שמור ב-localStorage

#### 🏷️ **תגיות (Tags/Labels)**
```
"bug", "feature", "docs", "refactor"
```
- שדה קטן בעריכת משימה
- כל משימה יכולה להיות עם מספר תגיות
- סינון לפי תגיות

#### 👤 **מי עובד על זה? (Assignee)**
```
בחר שם מהרשימה או "אף אחד"
```
- קל לעקוב מי אחראי
- צבע שונה בקרטה עבור כל אחד

#### ⏰ **תאריך סיום (Due Date)**
```
"היום", "מחר", "בשבוע", "עדיין לא"
```
- תזכורת ויזואלית באדום אם עבר המועד
- סרטן משימות לפי תאריך

#### 📊 **סטטיסטיקה פשוטה**
```
- כמה משימות בכל עמודה
- כמה שסיימו (%)
- כמה קריטי
```

#### 🔍 **חיפוש וסינון**
```
- חיפוש בכותרת/תיאור
- סינון לפי מצב, תעדוף, תגיות
```

#### 🖨️ **Export & Backup משופרים**
```
- Export לـ CSV (לכל פרוייקט)
- Export לـ PDF (דוח)
- Backup אוטומטי כל 5 דקות
```

### מורכבים יותר (ולא הכרחיים):

- **Drag & Drop** - גרור משימה בין עמודות
- **Quick Actions** - לחץ ממש וקדימה עדכון
- **User Profiles** - תמונה + צבע לכל משתמש
- **Team Collaboration** - שתף קישור (Sync עם URL)
- **Time Tracking** - כמה שעות במשימה?
- **Recurring Tasks** - משימה חוזרת כל שבוע
- **Dependencies** - משימה A תלויה בתא B
- **Comments** - דיון על משימה
- **Activity Log** - עדכונים על מה השתנה

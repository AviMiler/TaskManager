# Task Manager - מערכת ניהול משימות 📋

מערכת פשוטה ומהירה לניהול פרוייקטים ומשימות **ישירות בדפדפן שלך** עם אחסון מקומי וגיבוי אוטומטי.

## ✨ תכונות

✅ **100% דפדפן** - אין צורך בשום סרוור או התקנות  
✅ **פשוט ומינימלי** - ממשק נקי וקל לשימוש  
🚀 **מהיר** - כל הנתונים נשמרים בדפדפן שלך  
💾 **גיבוי אוטומטי** - גיבוי דו-שכבתי בכל פעם שאתה משנה משהו  
📱 **רেספונסיבי** - עובד על דסקטופ וטלפון  
🔒 **מקומי לחלוטין** - כל הנתונים נשמרים בדפדפן - לא נשלחים לשום שרת  

## 🚀 התחלה

### דרך פשוטה ביותר:
1. כנס לתיקיית `TaskManager`
2. לחץ פעמיים על `index.html` **או** גרור אותו לדפדפן שלך
3. זהו! האפליקציה פתוחה ומוכנה להשתמש

### או בדפדפן:
1. פתח את הדפדפן שלך (Chrome, Firefox, Edge, Safari)
2. הקש `Ctrl+O` (Windows) או `Cmd+O` (Mac)
3. בחר את הקובץ `index.html`
4. לחץ "פתח"

## 💾 איפה הנתונים שלי?

כל הנתונים שלך נשמרים **בדפדפן שלך** (localStorage):

### יש שני קבצים "וירטואליים":
1. **tm_projects** - רשימת הפרוייקטים שלך
2. **tm_tasks** - כל המשימות שלך
3. **tm_backup** - גיבוי אוטומטי שנוצר בכל שינוי

אתה יכול לראות אותם ב:
- **Chrome/Edge**: `F12` → Application → Local Storage
- **Firefox**: `F12` → Storage → Local Storage

## 📖 איך משתמשים?

### ➕ הוסף פרוייקט
1. הקלד שם בשדה "שם פרוייקט חדש..." בשמאל
2. לחץ על הכפתור ➕ או לחץ Enter

### ➕ הוסף משימה
1. בחר פרוייקט מהרשימה בשמאל
2. הקלד כותרת משימה בשדה "כותרת המשימה..."
3. (אופציונלי) הוסף תיאור למטה
4. לחץ "➕ הוסף משימה" או לחץ Enter

### ✅ סמן כהשלום
- לחץ על הת"א (checkbox) ליד המשימה

### ✏️ ערוך משימה
- לחץ על הכפתור ✏️
- שנה את הכותרת או התיאור
- לחץ "שמור"

### 🗑️ מחק
- לחץ על 🗑️ ליד המשימה או הפרוייקט
- אישר את המחיקה

## ⚠️ זהירות!

### נטיפול למשתמשים מתקדמים:

**אם תמחק את ה-localStorage של הדפדפן**, כל הנתונים שלך יאבדו!
- **Chrome**: Settings → Privacy → Clear browsing data → Cookies and other site data
- **Firefox**: Preferences → Privacy → Cookies and Site Data → Clear Data
- **Edge**: Settings → Privacy → Clear browsing data

### איך לשמור גיבוי למחשב:
1. פתח את F12 (Developer Tools)
2. עבור ל-Application → Local Storage → (שם הדפדפן)
3. בחר את `tm_backup`
4. הוא יפתח בconsole - תוכל להעתיק אותו ולשמור לקובץ .json

## 🚀 טיפים שימושיים

- **Keyboard Shortcuts:**
  - `Enter` בשדה פרוייקט = הוסף פרוייקט
  - `Enter` בשדה כותרת משימה = הוסף משימה
  - `Esc` בחלון עריכה = בטל

- **עזרה לנתונים תקועים:**

## 📝 מה אם נתקל בבעיה?

### הנתונים לא נשמרים:
1. וודא שהדפדפן מאופשר אחסון (localStorage)
2. בדוק שאתה לא בתצורת "Incognito/Private"
3. וודא שדיסק קשיח יש מקום פנוי

### הקובץ לא נפתח:
1. תנסה דפדפן אחר
2. וודא שאתה פותח את `index.html` (לא css או js)
3. אם זה עדיין לא עובד, תוכל להעתיק את הטקסט מה-html לקובץ חדש
